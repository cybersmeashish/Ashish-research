# Ashish Research

Security research notes and reference designs connecting cybersecurity, AI security, and business decisions.

Each contribution separates primary-source guidance, original design choices, and observed results. Synthetic examples are labeled, and proposed controls are not presented as validated protections.

## Reference scenario

**Sentinel Logistics** is a fictional company used to connect the research. Its customer order service gains an AI assistant, retrieval, and tools. Later contributions will examine cloud, identity, model integrity, detection, and connected systems using owned or simulated environments.

This repository begins with a design and evidence note. It does not contain a production assessment, a discovered vulnerability, or a claim of compliance.
